# toolroom

Typed surfaces for command-line tools, generated from the tools
themselves.

Nothing lives here yet. The name is reserved for the planned spinoff of
[footman](https://github.com/willemkokke/footman)'s tools bridge, stub
generator, and tool store, and the work currently happens there. The
machine-shop sense of the word is the plan: the toolroom is where
precision tools are made, kept with their measurements, repaired when
they drift, and issued for use.
